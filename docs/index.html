GeoLogger

歩いた場所を Android 端末に記録し、自分のサーバーへ送り、 CSV / GPX / GeoJSON で書き出せる位置情報ロガーです。

APK をダウンロード

バージョン 1.0 ・ 約 1.3 MB ・ Android 8.0 以上
ソースコードと更新履歴（GitHub）

できること

端末に記録する

画面を消していても記録が続きます。保存先は端末内のデータベースで、数十万点ためても平気です。

軌跡を見る

記録した座標だけで線を描くので、地図データを読み込みません。圏外でも表示できます。

自分のサーバーへ送る

記録した位置を自分で用意したサーバーへ送れます。圏外のぶんは溜めておき、つながったら送ります。

書き出す

CSV・GPX・GeoJSON で取り出せます。共有メニューに渡すか、ダウンロードフォルダに保存します。

入れかた

  1. APK をダウンロードする

    上のボタンを押します。Android が「この種類のファイルは端末に危害を及ぼす可能性があります」と出しますが、そのまま続けて構いません。

  2. インストールを許可する

    ダウンロードした APK を開くと「提供元不明のアプリ」の確認が出ます。ブラウザやファイルアプリに対して許可してください。Google Play を経由しないアプリは、すべてこの確認が出ます。

  3. 位置情報を「常に許可」にする

    アプリを開いて Log → Start recording を押すと権限を聞かれます。かならず「常に許可」を選んでください。「アプリの使用中のみ許可」では、画面を消した時点で記録が止まります。

  4. 記録が始まる

    記録中は通知バーに常駐の通知が出ます。Android の決まりで、位置情報を裏で使うアプリはこの通知を消せません。通知の「Stop」からいつでも止められます。

電池について。 既定では 1 分ごとに測位し、30 m 以上動いたときだけ記録します。止まっているあいだは何も記録せず通信もしないので、机に置いたままなら電池はほとんど減りません。間隔は Settings → Recording で変えられます。

画面の見かた

Log記録の開始と停止、ためた点の数、送信の状況、直近の測位の一覧。
Map軌跡の表示。今日 / 7 日 / 全部で切り替えられます。線をタップするとその地点の時刻と座標が出ます。最後の区間だけ色が違うのは、進んでいる向きを示すためです。
Export書き出し。形式と範囲（全部 / 今日 / 7 日 / 未送信のみ）を選びます。書き出してもアプリ内のデータは消えません。
Settings送信先サーバー、送信のしかた、測位の間隔、たまったデータの削除。

サーバーへ送る設定

サーバーへ送らず、端末内の記録と書き出しだけで使うこともできます。送る場合は Settings → Server account に送信先の URL・ID・パスワードを入れてください。入れるまで、記録した点は送られずに端末へたまり続けます。

送信のしかた

Send every fix記録するたびに 1 件ずつ送ります。サーバーに残る時刻が実際の測位時刻に近くなります。
Send in batches決めた数（5〜50）たまってからまとめて送ります。通信の回数が減るぶん電池に優しいです。

まとめて送る設定では、たまりきらないぶんは次に動くまで端末に残ります。すぐ送りたいときは Log タブの「Upload now」を押してください。

サーバー側の受け口

自分でサーバーを用意する場合、アプリは次の形で送ります。

POST application/x-www-form-urlencoded

1件   mode=add&id=..&pw=..&lat=35.680000&lon=139.761600[&c=A1B][&t=1791357596]
まとめて mode=add&id=..&pw=..&d=35.680000,139.761600,A1B[,1791357596]&d=...
  • t は測位した時刻（UNIX 秒）です。サーバーが対応してから Settings → Sending → Send timestamps で有効にしてください。未対応のまま有効にすると、すべての送信が失敗します。
  • 応答が 2xx なら送信済みとして扱います。4xx は「直さないかぎり直らない」と判断して自動送信を止めます（設定を直すか「Upload now」で再開）。5xx や通信エラーは次の機会に自動で送り直します。
  • URL は https:// で指定してください。http:// だとリダイレクトで送信内容が失われることがあります。

書き出せる形式

CSV全項目。表計算ソフトで開けます。
id,timestamp,datetime_iso,latitude,longitude,accuracy_m,altitude_m,speed_mps,uploaded
GPXGPS 機器や地図ソフトの標準形式。1 点ごとに時刻を持ちます。軌跡を線として見たいときはこちら。
GeoJSON1 回の測位を 1 つの地点として並べます。地図ライブラリや GIS で読むとき向け。

うまく動かないとき

画面を消すと記録が止まる

位置情報の権限が「常に許可」になっているか確認してください。Android の設定 → アプリ → GeoLogger → 権限 → 位置情報 から変えられます。

しばらくすると勝手に止まる

一部のメーカー（Xiaomi、Huawei など）の省電力機能が、裏で動くアプリを止めることがあります。Settings の一番下にある「Exclude from battery optimisation」から、電池最適化の対象外にしてください。

送信に失敗する

Log タブの Upload 欄に理由が出ます。HTTP 400 なら ID かパスワードの間違い、または t に未対応のサーバーで Send timestamps を有効にしている場合です。記録した点は消えないので、設定を直して「Upload now」を押せば送られます。

技術的なこと

  • Kotlin + Jetpack Compose で書いた素の Android アプリです。Google Play 開発者サービスを使わないので、GMS の入っていない端末でも動きます。
  • 対応は Android 8.0 以上（minSdk 26 / targetSdk 36）。
  • 記録した位置が外に出るのは、自分で設定した送信先だけです。ほかのどこにも送っていません。広告も解析も入っていません。
  • ソースは GitHub にあります。
